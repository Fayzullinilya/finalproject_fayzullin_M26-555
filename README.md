# ValutaTrade Hub

Консольное приложение для отслеживания курсов валют и криптовалют, ведения
собственного портфеля активов и истории сделок. Данные о курсах загружаются
из внешних API, кешируются локально и логируются в журнал.

## Возможности

- Загрузка актуальных курсов с CoinGecko (криптовалюты) и ExchangeRate-API
  (фиатные валюты).
- Хранение полного журнала курсов (история значений) и локального кеша
  с последним состоянием.
- Просмотр курсов с фильтрацией, сортировкой и пересчётом относительно
  произвольной базовой валюты.
- Учёт портфеля: покупка и продажа валют с расчётом по актуальному курсу
  и историей операций.
- Логирование работы парсера в файл.

## Архитектура 
разделена на три слоя:
CLI отвечает только за ввод, валидацию аргументов и вывод в консоль
use cases — за бизнес-логику
parser/storage — за работу с внешними API и файлами данных.
